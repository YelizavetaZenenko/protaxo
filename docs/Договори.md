# Договори (Contract)

Договір з [[Контрагенти|контрагентом]]. Пакет `com.example.protaxo.contract`, URL `/contracts`, `/api/contracts`.

## Поля

- `clientId` — FK на [[Контрагенти]]
- `contractNumber` — унікальний
- `status` — enum `ContractStatus { ACTIVE, SUSPENDED, TERMINATED }`

## Використовується в

Раніше — модулем "Наряди" (Order, `contractId` опційний FK). Той модуль **повністю видалений** — див. [[Рішення і відхилення]]. Зараз Договори існують як самостійний довідник без інших модулів, що на них посилаються.

# Технологічний стек

- **Java 21**, **Spring Boot 4.1.0** (не 3.x, як зазначено в оригінальній специфікації — див. [[Рішення і відхилення]])
- **PostgreSQL 16** (у Docker) — база `protaxo`, контейнер `protaxo_postgres`
- **Flyway** — усі зміни схеми лише через міграції (`src/main/resources/db/migration`), Hibernate працює в режимі `ddl-auto=validate` і нічого сам не створює
- **Spring Data JPA / Hibernate 7.4.1** — соft delete (`deletedAt`) + auditing (`createdAt`/`updatedAt`) через `BaseEntity` і `@EnableJpaAuditing`
- **Spring Security** — сесійна автентифікація для сайту + HTTP Basic для API (див. [[Безпека і ролі]])
- **Thymeleaf** — серверний рендеринг сторінок, `thymeleaf-extras-springsecurity6` для `sec:authorize` у шаблонах
- **MapStruct 1.6.3** + **Lombok** — мапери Entity ↔ DTO, зменшення шаблонного коду
- **openhtmltopdf** (`openhtmltopdf-pdfbox`) — генерація PDF з Thymeleaf-шаблонів (спадкоємець Flying Saucer, названого в оригінальній специфікації). Детальніше — [[PDF-генерація]]
- **spring-boot-starter-mail** + **MailHog** (Docker, локальна розробка) — листи-запрошення для нових користувачів. Детальніше — [[Реєстрація акаунтів (запрошення)]]
- Мінімальний власний CSS (`static/css/style.css`), без сторонніх фреймворків і CDN

## Особливість Spring Boot 4

Autoconfigure розбитий на дрібні модулі. Flyway сам по собі (`flyway-core`) більше не тягне автоконфігурацію — потрібна ще окрема залежність `org.springframework.boot:spring-boot-flyway`. Без неї міграції просто не запускаються без жодної помилки в консолі (виглядає, ніби Flyway працює, але таблиці не створюються).

## Архітектура коду

Вертикальні зрізи по модулях (не по шарах): кожен модуль (`client`, `vehicle`, `order`, `invoice`, `catalog`, `security`...) має свої `entity/ dto/ mapper/ repository/ service/ controller/ web/`. Контролери діляться на:
- REST (`*Controller`, `/api/...`) — повертають DTO, для Postman/зовнішніх інтеграцій
- Web (`*PageController`, без префіксу `/api`) — рендерять Thymeleaf-сторінки, використовують ті самі Service

Див. [[Запуск проєкту]] для інструкцій зі старту.

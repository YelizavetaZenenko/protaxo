Модуль фактично повний відносно оригінальної специфікації `ARCHITECTURE.md` 4.6.

## Пропозиція для наступних кроків (за пріоритетом реальної цінності, оновлено 2026-09-16)

1. **[[Print Agent]] — реальний тест на фізичному TSC-принтері.** Весь канал (WebSocket, TSPL-генерація, `javax.print`, попередній перегляд, публічна перевірка за QR) уже реалізований і перевірений без принтера — лишився сам факт друку "на папері": розмір наклейки, позиції тексту/QR, кирилиця через CP1251. Найдешевша й найшвидша дія з усього списку, бо решта коду вже готова
2. Розгортання на окремому сервері — **рішення прийняте (2026-09-17): хмарний VPS**, не власне залізо (користувачка не хоче тримати сервер фізично вдома/в офісі). Деталі й практичний план (Dockerfile застосунку, prod docker-compose з Caddy/HTTPS, VPN, Linux-бекап) — [[Варіанти розгортання (сервер)]]. Тісно пов'язано з HTTPS (зараз лише HTTP — прийнятно для локальної мережі, але обов'язково перед виходом на VPS)
3. Role_Permissions — гнучкі права з JSON замість захардкоджених ADMIN/MASTER у `SecurityConfig`. Ніхто поки не просив конкретно — низький пріоритет, якщо не з'явиться реальна потреба
4. Якщо колись з'явиться реальний зразок "Акта виконаних робіт" — переробити `templates/pdf/act.html` під нього (той самий шлях, що вже двічі пройдено для "Рахунку на оплату")

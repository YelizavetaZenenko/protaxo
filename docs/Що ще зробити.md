Розрив між `ARCHITECTURE.md` і фактичним станом системи, станом на поточну сесію.

## Частково зроблено

- **`CalibrationProtocol`** — з реальним зв'язком з [[Наряд-заказ|Invoice]] і (з 2026-09-15) з [[Тахографи|Tachograph]], PDF-друком за офіційним бланком, блокуванням ключових полів після збереження, (з 2026-09-08) повним набором полів результатів калібрування — W/K/L, розмір і тиск шин, пробіг, відхилення шляху/швидкості/часу, обмежувач швидкості, реєстрація подій, виконавець (див. [[Протокол калібрування (CalibrationProtocol)#Повний набір полів результатів калібрування (2026-09-08)]]), (з 2026-09-15) номерами пломб + QR-хешем для наклейки [[Print Agent]], і (з 2026-09-16) датою наступної перевірки (похідне поле, +2 роки від дати протоколу). Модуль фактично повний відносно оригінальної специфікації `ARCHITECTURE.md` 4.6.

## Знахідки аудиту, свідомо не виправлені зараз (низький пріоритет)

- Токен запрошення/відновлення паролю теоретично можна використати двічі при одночасних запитах (read-then-write без атомарного захисту, `PasswordResetService`/`UserManagementService.acceptInvite`) — не веде до витоку даних, лише "останній запис перемагає"
- Порівняння токена Print Agent (`PrintAgentHandshakeInterceptor`) не є constant-time (`.equals`) — мінімальний ризик, трафік лише всередині Tailscale, не в публічному інтернеті
- `FieldSuggestionService.remember()` може створювати дублікати підказок (регістр + гонка станів при одночасному збереженні) — косметично, не ламає дані
- `UkrainianAmountWords` неправильно форматує від'ємні суми і мовчки "губить" суми ≥1 трильйон — обидва випадки нереальні для поточного масштабу бізнесу
- Потенційний невеликий resource leak (незакриті потоки шрифтів) у `PdfRenderService` при рендерингу PDF — потребує перевірки контракту `openhtmltopdf`, не підтверджено напевно

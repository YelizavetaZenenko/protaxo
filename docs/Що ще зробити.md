# Що ще зробити

Розрив між `ARCHITECTURE.md` і фактичним станом системи, станом на поточну сесію.

## Взагалі не почато

- **Hibernate Envers / по-польові діфи** — журнал дій ([[Журнал дій (Audit Log)]]) вже є, але лише на рівні події ("хто/що/коли"), без старого/нового значення по кожному полю. Envers додав би саме це, якщо колись знадобиться.
- **Генерація PDF для рахунків/актів** — "Рахунок на оплату" **вже зроблено** (окремий шаблон на основі зразка, наданого користувачем — див. [[Наряд-заказ]]). Акт — обговорення призупинено, чекає на відповідь користувача; тепер, коли модуль "Наряди" видалений, єдиний реалістичний кандидат-джерело — [[Наряд-заказ]]. `CalibrationProtocol` PDF **вже зроблено**.
- **Print Agent** — окремий фоновий сервіс на комп'ютері СТО, WebSocket-з'єднання з бекендом, друк наклейок на термопринтер (TSPL/ZPL). Велика окрема тема, поза межами самого бекенду.
- **Role_Permissions** — гнучкі права з JSON (`can_create_order`, `can_edit_completed` тощо). Зараз тільки захардкоджені правила ADMIN/MASTER у `SecurityConfig`.
